# Версия 4.2.9.9

- Добавлена возможность блокировки спама в чатах (PT-1098).
- Добавлена обработка идентификаторов WhatsApp LID и PN (PT-1090).
- Добавлена двухфакторная авторизация для мессенджера MAX.
- Добавлена настройка отключения загрузки групповых чатов (PT-1069).
- Добавлена загрузка моделей речевой аналитики через API.
- Добавлена загрузка истории звонков начиная с выбранной даты.
- Для сервиса распознавания речи используются отзываемые API-токены (PT-1108).
- В распознавание речи передаются аудиозаписи в формате OGG.
- Исправлено определение каналов оператора по метаданным записей WebM (PT-1104).
- Предотвращено создание отдельных чатов WhatsApp для идентификаторов PN и LID (PT-1103).
- При создании чата учитывается доступность учетной записи мессенджера (PT-1101).
- В групповых чатах не выполняется автоматический подбор клиента (PT-1102).
- Уточнена фоновая проверка статусов учетных записей мессенджеров (PT-1105).
- Добавлена проверка webhook-подписок MAX (PT-1087).
- Добавлено отображение пересланные сообщений MAX.
- Не загружаются события MAX-бота без сообщения (PT-1099).
- Исправлено отображение цитаты ответа в MAX Bot.
- Исправлено повторное добавление вложений MAX (PT-1096).
- В MAX отображаются ошибки лицензирования (PT-1095).
- После авторизации Telegram по QR-коду поддерживается ввод пароля 2FA (PT-1078).
- Исправлена обработка неполного статуса учетной записи Telegram (PT-1094).
- В плеере отображается отсутствие записи разговора (PT-1089).
- Обработаны ошибки очереди распознавания речи (PT-1111, PT-1112).
- Исправлена ошибка отображения кнопки "ещё события" в ленте (PT-1092).
- Убрано ложное сообщение об ошибке баланса ИИ (PT-1093).
- Исключена повторная отправка отредактированных сообщений (PT-1106).
