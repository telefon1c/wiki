# Версия 4.2.8.3

- Добавлена поддержка мессенджера MAX с возможностью написать первым.
- Добавлены кнопки в карточку клиента для отправки сообщений в MAX.
- Добавлена поддержка пересланных сообщений MAX ботом.
- Добавлена проверка ограничений Telegram аккаунта перед отправкой сообщения по номеру телефона.
- Используются параметры прокси-сервера при проверке статусов учетных записей.
- Длина номера телефона увеличена до 32 символов для отправки исходящих сообщений в Telegram по никнейму (PT-1081).
- Исправлена проблема с удалением комментария в звонке после синхронизации с документом "Телефонный звонок" в CRM конфигурациях (PT-1084).
- Исправлена ошибка в команде диагностики модуля УМ (PT-1079).
- Добавлена дополнительная сортировка итоговой таблицы для гарантии порядка строк таблицы маршрутизации (PT-1076).
- Исправлена проблема аварийного завершения сеанса 1С при первом входе после обновления расширения телефонии, если сервер АТС недоступен (PT-1074).
- Исправлена функция "Проверка по номеру телефона" в форме настроек УМ (PT-1075).
- Исправлена ошибка "Клиент не определен для данного вида объектов" при отправке сообщения мессенджера из контакта (PT-1068).
- Исправлена проблема с предзаполнением формы отправки сообщения.
- По умолчанию включено автоматическое закрытие чатов (PT-1077).
