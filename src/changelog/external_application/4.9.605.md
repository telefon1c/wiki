# Версия 4.9.605

## Новые возможности

- Полная поддержка компьютеров Mac с процессорами Apple Silicon и Intel: приложение работает быстрее и стабильнее, обновления автоматически подбираются под тип процессора.
- Новая вкладка «Разрешения» в настройках — проверка доступа к микрофону и уведомлениям (macOS).
- Чат: перенос строки по Shift+Enter, панель часто используемых эмодзи, выбор нескольких эмодзи подряд, крупное отображение сообщений из одних эмодзи.
- Файлы из чата сохраняются в папку «Загрузки» в один щелчок с возможностью сразу показать файл в папке.

## Улучшения

- Чат работает заметно быстрее: история подгружается заранее, отправленные сообщения появляются мгновенно, поле ввода не блокируется при быстрой серии сообщений.
- Статусы «доставлено» и «прочитано» у сообщений обновляются в реальном времени.
- Счётчик непрочитанных сообщений надёжно отображается на значке приложения в Windows и macOS (включая Dock и переключатель приложений).
- Кнопка закрытия окна на macOS теперь учитывает настройку «Сворачивать при закрытии».

## Исправления

- Устранены «зависшие» и фантомные звонки: после отмены перевода, при отбое звонка из очереди, при перехвате и при одновременном входящем с двух направлений.
- Исправлены проблемы со звуком: микрофон не освобождался после разговора, пропадал звук при автоответе, сбивалась громкость после параллельного звонка.
- Чат: исправлены самопроизвольная прокрутка, задвоение сообщений, мигание отправляемых изображений, ложный счётчик непрочитанных и редкие зависания.
- Исправлено воспроизведение записей разговоров при работе через прокси-сервер, а также ошибка автообновления в Windows.
