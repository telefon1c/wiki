# Клиенты

В разделе **Клиенты** отображаются клиенты из 1С, с которыми недавно велась переписка в чатах или были звонки. Также доступен поиск по клиентской базе.

Для каждого клиента можно посмотреть ответственного сотрудника, выполнить звонок и открыть боковую карточку с основной информацией.

В карточке отображаются общие данные клиента, контактная информация, местоположение и местное время. Это удобно при работе с клиентами из разных регионов.

При необходимости можно открыть карточку клиента в 1С, чтобы посмотреть более подробную информацию.
