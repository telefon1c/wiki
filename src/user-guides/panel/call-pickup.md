# Перехват вызова

Возможность перехвата вызова настраивается для пользователей в разделе Звонки и сообщения → Настройки → Дополнительные разрешения в 1С.

Функция перехвата вызова позволяет сотруднику принять входящий звонок, который поступает другому сотруднику, прямо из панели.

Как работает:
1. Входящий звонок обрабатывается по стандартному правилу маршрутизации, настроенному на АТС.
2. Пока сотрудник не ответил на звонок, пользователь может принять вызов из списка сотрудников. Для этого нужно нажать кнопку Перехват в строке сотрудника, которому поступает звонок.
3. Звонок сразу переведется на пользователя, выполнившего перехват, и перестанет поступать коллеге. Пользователь отвечает на вызов и начинает разговор с клиентом.

Если звонок завершился или на него уже ответили, перехват не выполняется.
