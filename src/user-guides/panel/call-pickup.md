# Перехват вызова
Возможность перехвата вызова настраивается для пользователей в дополнительных разрешениях в 1С.

Функция перехвата вызова позволяет ответственному сотруднику увидеть входящий вызов, доступный для перехвата, и принять его вручную прямо из панели. Ответственный - сотрудник, который в 1С назначен ответственным для данного клиента.

Это позволяет быстрее соединить клиента с сотрудником, который с ним работает, без ожидания в очереди или дополнительного перевода через секретаря.

Как работает:
1. При поступлении внешнего входящего вызова он обрабатывается по стандартному правилу маршрутизации, настроенному на АТС. Одновременно вызов отображается в панели у ответственного сотрудника, если для клиента такой ответственный назначен и звонок доступен для перехвата.
2. В течение заданного времени ответственный видит входящий вызов и может вручную перехватить его из панели.
3. Если **ответственный сотрудник перехватывает вызов**, звонок переводится на него, и он начинает разговор с клиентом. <br>
   Если **ответственный не перехватывает вызов** в течение отведенного времени, вызов у него прекращается, а звонок продолжает обрабатываться стандартным способом. <br>
   Если **трубку поднимает другой участник стандартной обработки звонка раньше ответственного**, вызов у ответственного также прекращается.

Если участник очереди еще не поднял трубку, ответственный все еще может перехватить звонок из списка сотрудников. Для этого нужно нажать кнопку Перехват в строке сотрудника, на которого в данный момент поступает этот вызов.
