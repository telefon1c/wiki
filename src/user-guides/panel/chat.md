# Чаты с клиентами
!!!
**Подготовка информационной базы к работе с чатами**

Для работы чатов необходимо выполнить первоначальную настройку информационной базы:
1. <a href='/get-started/nastroyka_1c/#зарегистрируйтесь-в-системе-взаимодействия'>Зарегистрировать информационную базу</a> в системе взаимодействия.
2. <a href='/faq/base-publishing'>Настроить публикацию</a> информационной базы на веб-сервере.
3. <a href='/get-started/whatsapp/#смена-способа-соединения-с-long-polling-на-веб-сервис'>Установить режим соединения 1С</a> с АТС через веб-сервис.

После выполнения этих настроек необходимо выполнить авторизацию в чатах в Панели телефонии.
!!!

Раздел Чаты предназначен для обработки входящих обращений клиентов из подключенных в 1С каналов связи. В интерфейсе оператор видит очередь нераспределенных чатов, свои активные диалоги и чаты, за которыми он наблюдает.

Поддерживается работа с чатами из WhatsApp, Telegram и MAX. Это позволяет операторам обрабатывать обращения из разных мессенджеров в едином рабочем пространстве.

Новые обращения попадают в блок **Очередь** и ожидают принятия в работу. Оператор может открыть такой диалог, ознакомиться с сообщениями и принять чат в работу. После этого чат переходит в список **Мои чаты**, а сотрудник становится ответственным.

Чаты, в которых сотрудник назначен наблюдателем, отображаются в блоке **Наблюдаемые**. Инструкция по добавлению наблюдателя в чат описана здесь.
